Engineering

Software Engineer

India / Hybrid • Full Time • Arshith Core Engineering

Role Overview

As a Software Engineer at Arshith Info-Tech, you will build and scale mission-critical web applications, backend APIs, and enterprise digital solutions. You will collaborate with cross-functional squads to engineer clean, maintainable, and high-performance software.

Key Responsibilities

  • Design, develop, and test modular backend services and responsive frontend interfaces.
  • Write robust unit, integration, and end-to-end automated test suites.
  • Participate in peer code reviews, architectural discussions, and agile sprints.
  • Optimize application performance, database queries, and API response latencies.

Required Skills

JavaScript / TypeScript Node.js / Python / Java React / Modern Web REST / GraphQL APIs SQL / NoSQL Databases

Preferred Qualifications

  • Familiarity with Docker containerization and CI/CD pipelines.
  • Strong understanding of software design patterns and distributed architectures.
AI & Data

AI / ML Engineer

India / Hybrid • Full Time • Arshith AI Practice

Role Overview

Join our AI & Intelligent Solutions squad to develop, fine-tune, and deploy state-of-the-art machine learning models, generative AI pipelines, and predictive analytics tools for enterprise clients.

Key Responsibilities

  • Build and deploy ML inference pipelines and agentic generative AI workflows.
  • Fine-tune open source LLMs on proprietary domain data with strict guardrails.
  • Collaborate with data engineers to construct clean ETL training pipelines.
  • Monitor model drift, latency, and inference cost efficiency.

Required Skills

Python / PyTorch / TensorFlow Generative AI / LLMs / RAG Vector Databases MLOps & Model Deployment Pandas / NumPy

Preferred Qualifications

  • Experience with LangChain, LlamaIndex, or agentic frameworks.
  • Published AI/ML projects or contributions to open-source models.
Cloud

Cloud Engineer

India / Hybrid • Full Time • Arshith Cloud Platform Team

Role Overview

Architect, provision, and maintain secure, highly available cloud infrastructures across AWS, Azure, and Google Cloud Platform. You will implement automated Infrastructure as Code (IaC) and reliable CI/CD pipelines.

Key Responsibilities

  • Implement Infrastructure as Code using Terraform and CloudFormation.
  • Manage Kubernetes (EKS/AKS/GKE) clusters, service meshes, and ingress controllers.
  • Implement FinOps strategies to monitor and optimize cloud expenditure.
  • Ensure disaster recovery, automated backups, and multi-region resilience.

Required Skills

AWS / Azure / GCP Kubernetes & Docker Terraform / Ansible CI/CD (GitHub Actions / GitLab) Linux / Bash / Python

Preferred Qualifications

  • Certified Cloud Architect or Certified Kubernetes Administrator (CKA).
Cybersecurity

Cybersecurity Analyst

India / Hybrid • Full Time • Arshith Cyber Defense Center

Role Overview

Protect enterprise digital ecosystems by evaluating vulnerability vectors, configuring zero-trust network boundaries, and responding to cyber incidents across cloud and on-premise environments.

Key Responsibilities

  • Conduct periodic vulnerability assessments and penetration testing.
  • Monitor SIEM/SOC alerts and orchestrate rapid incident response.
  • Implement Identity and Access Management (IAM) and least-privilege policies.
  • Ensure compliance with ISO 27001, SOC 2, and GDPR standards.

Required Skills

SIEM / SOAR Tools Zero-Trust Architecture Network Security & Firewalls Vulnerability Assessment OWASP Security Standards

Preferred Qualifications

  • CompTIA Security+, CEH, or CISSP certifications.
